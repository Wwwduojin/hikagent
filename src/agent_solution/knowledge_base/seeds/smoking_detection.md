# 抽烟识别算法流程

## 适用场景

用于园区、工厂、仓库、办公区域或公共空间的视频/图像抽烟行为识别，适合固定摄像头或巡检摄像头采集的数据。

## 算法目标

识别人员是否存在抽烟行为，并输出抽烟事件、人员位置、证据帧、发生时间段和置信度。

## 输入输出

- 输入：视频流、图片序列或单张图片；可选摄像头位置、区域配置、检测阈值。
- 输出：是否抽烟、人员框、手部/口部/香烟候选区域、事件时间段、证据帧、置信度。

## 核心流程

1. 检测人体、人脸、手部和香烟候选区域。
2. 对同一人员进行多帧跟踪，建立人员轨迹。
3. 判断手部靠近口部的动作关系，形成手-口动作特征。
4. 使用香烟细长目标、亮点、烟雾纹理等视觉特征作为辅助证据。
5. 对连续多帧置信度进行融合，过滤单帧误检。
6. 达到事件阈值后输出抽烟事件和证据帧。

## 关键约束

需要处理遮挡、低光照、小目标香烟、摄像头角度偏斜和多人重叠。实时场景需要控制检测模型和跟踪模块耗时。

## 常见误报

喝水、吃东西、打电话、摸脸、佩戴口罩反光、背景烟雾或蒸汽都可能造成误报。建议使用动作时序和多证据融合降低误报。

## 评估指标

precision、recall、F1、误报率、漏报率、事件级准确率、平均告警延迟。
