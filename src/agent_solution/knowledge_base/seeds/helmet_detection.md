# 安全帽佩戴识别算法流程

## 适用场景

用于工地、厂区、仓库和生产车间的人员安全帽佩戴状态检测。

## 算法目标

识别人员是否佩戴安全帽，并输出未佩戴安全帽事件、人员位置、证据帧和置信度。

## 输入输出

- 输入：监控视频流、图片序列或单张图片；可选作业区域配置。
- 输出：人员框、安全帽框、佩戴状态、未佩戴事件、置信度、证据帧。

## 核心流程

1. 检测人体和头部区域。
2. 在头部附近检测安全帽目标。
3. 判断安全帽与头部空间关系，区分佩戴、未佩戴和不确定状态。
4. 对同一人员进行短时跟踪，融合多帧结果。
5. 对连续未佩戴结果触发告警。

## 关键约束

需要处理远距离小目标、帽子颜色多样、头部遮挡、强光反射和人员密集场景。

## 常见误报

普通帽子、头发高光、头盔被手持、头部被遮挡时容易误判。建议结合人体框和头部位置进行约束。

## 评估指标

precision、recall、F1、未佩戴事件召回率、误报率、单帧检测速度。
