# 跌倒检测算法流程

## 适用场景

用于养老院、医院、工厂、公共区域等场景中的人员跌倒事件识别。

## 算法目标

识别人员从正常姿态转变为跌倒状态的事件，并输出事件时间段、人员位置、证据帧和置信度。

## 输入输出

- 输入：视频流或图片序列；可选区域配置和摄像头安装角度。
- 输出：跌倒事件、人员框、姿态状态、事件开始时间、证据帧、置信度。

## 核心流程

1. 检测并跟踪人员目标。
2. 估计人体关键点或人体框长宽比、中心点变化和运动速度。
3. 判断从站立/行走到水平姿态或异常静止的时序变化。
4. 融合姿态、速度、持续时间和区域规则。
5. 连续满足跌倒条件后输出事件。

## 关键约束

需要处理摄像头俯视角、遮挡、多人交错、坐下躺下等相似动作。事件判断应避免只依赖单帧姿态。

## 常见误报

弯腰、坐下、躺椅休息、捡东西、运动训练都可能被误判为跌倒。建议加入持续时间和异常静止判断。

## 评估指标

事件级 recall、precision、F1、平均告警延迟、误报率、漏报率。
