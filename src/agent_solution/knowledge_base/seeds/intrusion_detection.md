# 区域入侵检测算法流程

## 适用场景

用于厂区、仓库、机房、危险区域、围栏和禁入区域的人员或车辆入侵检测。

## 算法目标

识别目标进入指定区域或越过警戒线的事件，并输出目标位置、入侵区域、时间段和置信度。

## 输入输出

- 输入：视频流或图片序列；必须包含区域多边形或警戒线配置。
- 输出：入侵事件、目标类别、目标框、区域编号、事件时间段、证据帧、置信度。

## 核心流程

1. 检测人员、车辆或其他关注目标。
2. 对目标进行多帧跟踪，获得稳定轨迹。
3. 将目标脚点或中心点映射到配置区域。
4. 判断是否进入区域、停留超时或越线。
5. 对连续多帧命中进行融合，输出入侵事件。

## 关键约束

区域配置要与摄像头画面匹配。远距离小目标、阴影、反光和摄像头抖动会影响稳定性。

## 常见误报

目标框漂移、影子进入区域、区域边界配置过宽、动物或非关注目标可能触发误报。建议使用目标类别和轨迹稳定性过滤。

## 评估指标

事件级 precision、recall、F1、误报率、漏报率、区域命中准确率、告警延迟。
