# 明火烟雾检测算法流程

## 适用场景

用于仓库、厂区、林区、机房和公共空间的视频明火/烟雾早期检测。

## 算法目标

识别画面中的明火或烟雾异常，输出火焰/烟雾区域、事件时间段、证据帧和置信度。

## 输入输出

- 输入：视频流、图片序列或单张图片；可选区域配置和报警阈值。
- 输出：明火事件、烟雾事件、目标区域、事件时间段、证据帧、置信度。

## 核心流程

1. 检测火焰颜色、形状和纹理候选区域。
2. 检测烟雾的半透明纹理、扩散形态和运动变化。
3. 使用多帧时序判断火焰闪烁或烟雾扩散趋势。
4. 结合区域规则和置信度阈值过滤背景干扰。
5. 连续多帧满足条件后输出告警事件。

## 关键约束

需要处理光照变化、屏幕反光、雾气、蒸汽、灯光闪烁和远距离小目标。早期烟雾检测通常比明火检测更容易误报。

## 常见误报

车灯、警示灯、阳光反射、雾气、蒸汽、灰尘和视频噪声都可能造成误报。建议使用时序变化和场景区域约束。

## 评估指标

precision、recall、F1、误报率、漏报率、平均告警延迟、早期发现率。
